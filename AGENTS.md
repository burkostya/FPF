# Agent Notes

This repository contains the First Principles Framework (FPF) specification and related framework material. The large root Markdown files are canonical monolith exports, while the usable working material has already been split into smaller trees such as `fpf-spec/` and `nstd-framework/`.

Do not read large root-level Markdown monoliths in full. Files such as `FPF-Spec.md` and `Narrativization-and-Narrative-Studies-Principles-Framework.md` are large enough to waste context quickly. `Readme.md` is acceptable to read when useful. Use targeted searches and the split directories for the large monoliths.

For project context, prefer:
- `fpf-spec/title.md`, `fpf-spec/toc.md`, and targeted files under `fpf-spec/patterns/`
- `nstd-framework/title.md`, `nstd-framework/toc.md`, and targeted files under `nstd-framework/`
- `scripts/` for the split, compile, anchor, and verify tooling
- `.agents/skills/split-spec/SKILL.md` when working on the split-spec pipeline

Keep reads narrow: inspect only the files or ranges needed for the current task.
